# Data library and reuse policy

- Public information and materials may be used for project research.
- Save source files, transcripts, papers, documents, code, datasets, charts, notes, and artifacts that were actually used or are likely to be reused. Do not create a separate task to investigate storage permission.
- Full video files are not stored by default when transcripts, metadata, or notes are sufficient. Store the full file only when it materially helps the strategy or validation work.
- Preserve raw files immutably and version processed outputs.
- Every derived artifact records source or dataset IDs, transform version, timestamp, and checksum.
- Detect duplicates by canonical URL and SHA-256. Reuse existing material; quarantine conflicting duplicates instead of overwriting the original.
- Register durable material in a manifest so later chats can find it before repeating search, download, chart reconstruction, or analysis.
- Preserve invalidated experiments and failure reasons so other chats do not repeat them.
- Move superseded processed outputs and old snapshots to archive while keeping current registries small and queryable.
