# Operating playbook

1. Project State와 전략 순위를 읽고 수행할 범위를 정한다.
2. 그 범위와 관련된 Work Claim, Result, Validation, Source·Dataset·Entity, Run Report와 열린 PR만 검색한다.
3. 중복 비용이 크거나 산출물의 재사용 가치가 높은 작업에만 Work Claim을 만든다.
4. 기존 자료·데이터·차트·특징량·코드·백테스트·검증 증거를 재사용한다.
5. 초기 후보는 치명적 오류와 기본 비용으로 빠르게 선별한다.
6. 비용 후 가능성이 확인된 후보에만 아웃오브샘플·안정성·기간·종목·기본 체결 민감도를 추가한다.
7. 계좌·전략 선택이나 실사용 판단을 바꿀 후보에만 완전한 계좌·체결 스트레스와 필요한 독립 재현을 적용한다.
8. 판정 가능한 결과를 목표 근접도로 순위화한다. 1차 기준은 1% 비용 후 기하성장률 목표 격차이며 생존 조건을 함께 적용한다.
9. 실제 사용했거나 다시 찾을 가능성이 높은 자료만 최소 메타데이터로 등록한다.
10. 공용·재사용 가능한 변경은 브랜치·검증·커밋·PR로 반영한다.
11. 목표 달성, 시간제한, 판정 가능한 결과, 접근 전환 또는 상태 변경 시 완전한 Run Report를 작성한다.
12. 공통 상태 변경 전 최신 revision을 다시 확인하고, 중요한 변경만 milestone snapshot으로 남긴다.
