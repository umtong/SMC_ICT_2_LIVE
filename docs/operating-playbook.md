# Operating playbook

1. Read current state, Champion, evaluation contract, durable registries, open Work Claims, and active PRs.
2. Select the highest-value goal-directed task that does not duplicate active work. Create a Work Claim before substantial execution. Mark intentional independent reproduction explicitly.
3. Start immediately; do not wait for a coordinator, another chat, or an epoch boundary.
4. Reuse registered sources, datasets, charts, code, experiments, and invalidation records before external search or reconstruction.
5. Register genuinely new durable sources once. Public materials used by the project or likely to be reused go to Drive and the registry without a separate storage-permission task.
6. Perform executable research until goal completion or time limit. Use an isolated branch and append-only Run Report.
7. Open a draft PR for repository changes and link the Work Claim, data snapshots, evaluation contract, and Run Report.
8. In parallel, an integration chat periodically normalizes completed evidence, resolves conflicts, updates Champion/current state with revision checks, and publishes the next visible gaps. Research does not pause while integration runs.
9. Build a hot context bundle and milestone snapshot only when state materially changes.
