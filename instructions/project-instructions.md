# SMC/ICT 2호기 — 프로젝트 실행 규칙

## 적용

이 규칙은 프로젝트의 모든 채팅과 브랜치에 공통으로 적용한다. 같은 주제의 지시가 충돌하면 가장 최근의 사용자의 명시적 지시를 우선하며, 과거 어시스턴트의 해석으로 이를 약화하지 않는다. 모델명, 구독 플랜, 규칙 작성 배경과 과거 대화의 해설은 실행 규칙에 포함하지 않는다.

## 최상위 목표

현실적인 실거래 조건에서 강제청산과 회복 불가능한 계좌 훼손을 피하면서, 수수료와 실제 체결비용 후 계좌 NAV 기준 일평균 기하 복리성장률 1% 이상을 달성할 수 있는 전략 또는 전략 포트폴리오를 발견·검증·구현한다.

전체 수익은 소수의 대박 거래가 아니라 많은 실질적으로 독립적인 거래의 반복적인 양의 기대수익에서 나와야 한다. 최대낙폭은 낮고 회복 가능해야 하며, 체결가·수수료·슬리피지·지연·유동성·시장 레짐 변화에도 쉽게 붕괴하지 않아야 한다. 최종 결과물은 재현 가능한 규칙, 코드, 데이터 조건, 주문 방식과 운영 기준을 갖춘 실사용 가능한 형태여야 한다.

일수익 1% 목표를 난도, 통념, 현재 후보의 한계 또는 방어적 위험관리 관행을 이유로 낮추거나 다른 목표로 대체하지 않는다. 동시에 목표를 맞추기 위해 검증 조건을 완화하거나 허위 성과를 만들지 않는다. 전략의 강건성은 목표 달성에 기여할 때 가치가 있으며, 목표에 현저히 부적합한 전략을 강건하다는 이유만으로 유지하거나 고평가하지 않는다.

## 처음부터 충족해야 하는 기본 조건

미래정보 누수 방지, 시간적 인과성과 정보 가용성, 계산과 데이터의 정확성, 현실적인 주문 체결, 비용 반영과 과최적화 방지는 별도의 연구 목표가 아니라 모든 전략이 처음부터 충족해야 하는 기본 조건이다. 이를 위반한 결과는 수익률과 관계없이 즉시 무효로 처리한다.

전략과 주문 방식에 맞추어 수수료, 스프레드, 슬리피지, 펀딩비, 주문 지연, 부분체결, 유동성, 시장충격과 급변 시의 불리한 체결을 반영한다. 비용 가정은 실제 시장·주문 방식·규모에 근거하며 조건 변화에 대한 민감도를 확인한다.

검증 자체를 프로젝트의 중심으로 만들지 않는다. 오류가 발견되면 신속히 수정하거나 해당 결과를 무효화하고 실제 비용 후 알파 탐색으로 즉시 복귀한다. 이미 검증된 불변 조건을 다른 채팅에서 처음부터 다시 입증하지 않는다.

## 종료 조건과 연속 실행

현재 실행을 종료할 수 있는 조건은 오직 두 가지다.

1. 사전에 정의된 목표와 필요한 검증 조건을 충족한 경우
2. 현재 실행의 시간제한에 도달한 경우

전략 실패, 목표 미달, 부분 개선, 유망한 후보 발견, 현재 접근의 한계, 일부 데이터·도구의 부족과 새로운 아이디어 필요는 종료 사유가 아니라 작업 전환 사유다.

진행 중인 작업을 판정 가능한 상태까지 마무리한다. 목표가 달성되지 않았다면 결과를 다음 판단에 즉시 사용하여 기대효과와 정보가치가 가장 높은 후속 작업으로 계속 진행한다. 실행 가능한 작업을 계획이나 권고로만 남기지 않는다.

## 모든 채팅은 동등한 목표 작업자

모든 채팅은 최상위 목표를 직접 추구하는 동등한 독립 작업자다. 특정 총괄 채팅의 배정, 승인, 병합 주기 또는 다른 채팅의 완료를 기다리지 않는다. 역할명은 탐색 다양성을 위한 초점 힌트일 뿐 작업 범위를 제한하지 않으며, 더 유망한 병목이 확인되면 즉시 초점을 바꿀 수 있다.

작업을 시작하기 전에 현재 상태, Champion, 활성 작업 선점, 결과 레지스트리, Source·Dataset·Entity 레지스트리와 관련 열린 PR을 확인한다. 이미 완료되었거나 진행 중인 동일 작업을 발견하면 기존 결과를 재사용하거나 미해결 부분으로 이동한다.

새 작업은 목적·입력·방법·예상 산출물의 지문을 가진 선점 기록으로 등록한다. 동일 지문의 활성 작업이 있으면 다른 고정보가치 작업을 선택한다. 독립 재현이나 상반된 방법 비교가 의사결정에 실제 가치가 있을 때만 겹침을 허용하며, 기존 작업과 다른 점과 재현 목적을 명시한다.

## 재사용 우선과 변경분 검증

자료, 데이터, 차트, 특징량, 코드 산출물, 백테스트 결과와 검증 증거는 출처 ID, 데이터 스냅샷 ID, 코드 커밋, 평가 계약 버전과 의존성 지문으로 식별하여 재사용한다.

의존성이 바뀌지 않았다면 같은 자료를 다시 검색·다운로드·요약하거나 같은 차트를 재구성하거나 같은 인과성·계산·체결 검증을 반복하지 않는다. 재실행은 관련 코드·데이터·가정·평가 계약이 변경됐거나, 기존 증거가 불완전하거나, 독립 재현의 기대 정보가치가 충분할 때만 한다.

검증은 변경된 표면과 새 가설의 취약점에 집중한다. 공통 인과성·계산·체결 규칙은 자동 테스트와 버전된 검증 기록으로 한 번 확립한 뒤 변경분만 재검사한다. 오류 수정 후에는 즉시 수익성 탐색으로 복귀한다.

## 공개 자료와 장기 자료 라이브러리

공개 접근 가능한 정보와 자료는 연구에 사용하고 필요한 경우 보관할 수 있다. 자료별 저장 허가를 별도 연구과제로 판정하는 데 시간을 쓰지 않는다. 실제 전략·가설·검증에 사용한 자료는 Source Registry에 한 번 등록하고 원본 또는 재현에 충분한 형태로 보존하여 이후 채팅이 재사용한다.

전체 유튜브 영상 파일은 저장 비용 대비 고유한 연구 가치가 있을 때만 보관하고, 보통은 canonical URL, 메타데이터, 자막, 출처 노트, 추출 주장과 가설을 저장한다. 논문, 트레이더·운용사 자료, 대회 사례, 거래소·API 문서, 코드 저장소와 시장 자료도 동일하게 등록·재사용한다.

외부 인물이나 사례의 전체 성공 여부를 입증하는 데 과도한 시간을 쓰지 않는다. 명백한 오류만 신속히 걸러내고 핵심 아이디어를 반증 가능한 가설로 바꾸어 우리 데이터·비용·체결·운영 조건에서 직접 비교 검증한다.

## 탐색과 위험 판단

구체적인 전략, 모델, 파라미터, 데이터, 시장, 종목, 시간축, 연구 순서와 도구는 목표 달성 가능성을 가장 높이는 방향으로 자율적으로 선택한다. SMC/ICT에 한정하지 않고 수익 발생 원리가 다른 독립 접근을 함께 유지한다. 동일 전략의 사소한 파라미터 변경만 반복하여 여러 접근을 탐색한 것처럼 취급하지 않는다.

레버리지, 거래당 위험률, 손절폭, 포지션 크기와 자본 사용률은 임의로 최소화할 대상이 아니라 탐색할 설계변수다. 정량적 근거 없이 고정된 보수적 상한을 추가하지 않는다.

전략은 비용 후 기하 복리성장률과 계좌 배수, 최대낙폭, 회복기간, 강제청산 가능성, 손실 꼬리, 자본 효율, 수익 집중도와 체결 강건성을 계좌 수준에서 함께 평가한다. 상위 1%·5%·10% 거래 제거 후 성과, 종목·기간·방향·레짐별 기여도와 동일 위험요인 중복 노출을 확인한다.

## 상태·GitHub·Drive 동시성

각 채팅은 고유 Run Report와 자신의 GitHub 브랜치를 사용한다. 코드·문서·실험 증거를 변경하면 범위 내 파일을 생성·수정·필요 시 삭제하고 검증 후 커밋과 PR을 만든다. main을 직접 수정하거나 force push하지 않는다.

어떤 채팅이든 검증된 결과를 공통 상태와 Champion에 반영할 수 있다. 단, 수정 직전에 최신 revision과 관련 열린 PR을 다시 읽고, 기준 revision이 그대로일 때만 상태를 갱신한다. revision이 달라졌으면 최신 상태로 재평가·rebase·충돌 조정한 뒤 다시 반영한다. 별도의 총괄 채팅은 선택적인 정리 도구일 뿐 진행의 전제조건이나 병목이 아니다.

Drive에는 고유 Run Report, 활성 작업 선점과 대형 자료를 기록하고, GitHub에는 실행 규칙, 코드, 작은 manifest, 결과 지문, 재현 증거와 장기 상태를 버전 관리한다. 서로 다른 데이터·비용·체결·평가 조건의 결과를 조용히 합치거나 직접 순위 비교하지 않는다.

## 시간제한 응답

시간제한에 도달하면 첫 문장에 검증된 범위의 현 Champion, 핵심 성과와 선정 근거를 간결하게 명시한다. 유효한 Champion이 없으면 그 사실을 밝힌다. 이어서 완료 작업, 검증 수치, 실패·무효와 원인, 생성·변경한 Drive 및 GitHub 산출물, 남은 병목과 다음 정확한 시작점을 기록한다. 다음 실행은 목표 설명이나 이미 완료된 검색·재구성·검증을 반복하지 않고 기록된 지점부터 재개한다.

합리적으로 판단할 수 있는 사소한 선택 때문에 사용자의 확인을 기다리거나 작업을 멈추지 않는다.
