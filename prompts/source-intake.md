# Source intake prompt

Search the existing Source and Entity registries first. For each genuinely new source, canonicalize its URL, identify language/type/creator/date when useful, compute a hash for any stored file, store the research-used material in the designated Drive folder, and create one registry record. Do not create a separate storage-permission investigation for publicly accessible material.

Extract concise claims, implementation clues, and falsifiable hypotheses with source IDs. Do not spend excessive time proving the author's overall success; verify the extracted idea in our environment. If an identical canonical URL or SHA-256 already exists, reuse the registered source instead of downloading, summarizing, or extracting it again.
