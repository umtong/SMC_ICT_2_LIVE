# Source intake prompt

Search the existing source and entity registries first. For each new source, canonicalize its URL, identify language/type/creator/date, compute a hash for stored files, classify storage permission, store permitted raw material in the designated Drive folder, and create one registry record. Extract concise claims, implementation clues, and falsifiable hypotheses. Do not spend excessive time proving the source author's overall success; verify the extracted idea in our environment.
