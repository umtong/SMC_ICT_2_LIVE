# Source intake prompt

Search Source, Dataset, Entity, Hypothesis, Experiment, and open Work Claim registries first. Reuse existing materials and results before external search.

For a genuinely new durable source, canonicalize the URL, identify useful metadata, compute a hash for stored files, save the material used by the project or likely to be reused in the designated Drive folder, and create one registry record. Do not create a separate storage-permission investigation. Full video files are optional; use transcripts, documents, code, data, or notes when they contain what the research needs.

Extract concise claims, implementation clues, causal information boundaries, and falsifiable hypotheses. Do not spend excessive time proving the source author's overall success. Test the extracted idea directly in our environment and preserve the source linkage.
