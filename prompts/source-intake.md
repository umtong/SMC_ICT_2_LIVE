# Source intake prompt

수행 중인 가설·구현·검증과 관련된 Source·Entity Registry 항목만 검색한다. 동일 canonical URL이나 SHA-256이 있으면 기존 자료를 재사용한다.

실제 작업에 사용했거나 다른 작업에서 다시 찾을 가능성이 높은 새 자료만 등록한다. URL, 자료 유형, 핵심 관련성, 사용한 가설·실험, 원본 또는 재현 위치처럼 검색과 재현에 필요한 최소 항목부터 기록하고, 작성자·날짜·세부 태그는 필요할 때 보강한다. 사용하지 않은 검색 결과는 등록하지 않는다.

자료에서 핵심 주장, 구현 단서와 반증 가능한 가설을 source ID와 함께 추출한다. 외부 작성자의 전체 성공 여부보다 추출한 아이디어를 우리 환경에서 직접 검증하는 데 집중한다.
