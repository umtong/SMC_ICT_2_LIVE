# 새 프로젝트 구성

TARGET_GITHUB_REPOSITORY: `<새 GitHub 저장소 owner/name 또는 URL>`
TARGET_GOOGLE_DRIVE_ROOT: `<새 Google Drive 루트 폴더 URL 또는 ID>`

`umtong/SMC_ICT_2_LIVE`의 `bootstrap/bootstrap-contract.md`, `bootstrap/template-manifest.toml`, `bootstrap/drive-blueprint.json`을 읽고 위 두 위치에 동일한 목표와 연구 운영구조를 구성하라.

프로젝트 이름과 ID는 대상 GitHub 저장소 이름에서 파생한다. 현재 템플릿 프로젝트의 전략 결과, 순위, Work Claim, 자료·데이터 레지스트리, Run Report와 산출물은 상속하지 않는다. GitHub와 Drive를 revision 1, 빈 전략 순위와 빈 레지스트리로 초기화하고, 검증·커밋·PR·Drive bootstrap Run Report까지 실제로 완료하라. 실행 가능한 설정을 계획으로만 남기지 말라.
