# Time-limit checkpoint prompt

첫 문장에 현재 검증된 Champion과 선정 근거를 쓰거나 유효한 Champion이 없다고 명시한다. 완료 작업, 검증 수치, 재사용한 증거, 실패·무효 원인, Drive·GitHub 산출물, 남은 병목과 다음 정확한 작업을 기록한다.

현재 Work Claim을 완료·해제·갱신하고, 이번 실행이 판정 가능한 결과나 상태 변경을 만들었으면 완전한 append-only Run Report를 작성한다. 사소한 중간 진행만 있었다면 기존 작업 기록을 갱신하고 별도 보고서를 추가하지 않는다.

공통 상태나 Champion 변경이 필요하면 최신 revision과 관련 열린 PR을 다시 확인한다. 기준 revision이 바뀌었으면 재평가·rebase·충돌 조정 후 상태 PR을 만든다.
