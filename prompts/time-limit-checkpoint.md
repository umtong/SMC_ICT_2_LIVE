# Time-limit checkpoint prompt

첫 문장에 현 Champion, 검증 단계, 핵심 성과, 목표 대비 격차와 선정 근거를 쓴다. 비교 가능한 hard-valid 전략 또는 포트폴리오 후보가 전혀 없을 때만 Champion이 없다고 명시한다. Champion은 현재 순위 포인터일 뿐 연구 우선순위나 실사용 승인을 뜻하지 않는다.

완료 작업, 검증 수치, 재사용한 증거, 실패·하드 무효 원인, Drive·GitHub 산출물, 남은 병목과 다음 정확한 작업을 기록한다. 다음 작업은 Champion 주변 개선이 아니라 전체 목표 달성 가능성과 정보가치로 선택한다.

현재 Work Claim을 완료·해제·갱신하고, 이번 실행이 판정 가능한 결과나 상태 변경을 만들었으면 완전한 append-only Run Report를 작성한다. 사소한 중간 진행만 있었다면 기존 작업 기록을 갱신하고 별도 보고서를 추가하지 않는다.

판정 가능한 새 전략 결과가 있으면 현재 Champion과 비교하고 우수한 후보를 가리키도록 Champion 기록을 갱신한다. 이미 일반 결과 기록과 버전관리에 남은 이전 Champion을 다시 백업·복제·재검증하지 않는다. 공통 상태나 Champion 변경 전 최신 revision과 관련 열린 PR을 다시 확인하고, 기준 revision이 바뀌었으면 재평가·rebase·충돌 조정 후 상태 PR을 만든다.
