# Sources

## Market data

- Binance Vision official USD-M futures monthly kline archives:
  `https://data.binance.vision/data/futures/um/monthly/klines/`
- Every ZIP is checked against its official `.CHECKSUM` file before parsing.
- Final economic claims remain Bybit-specific; this source is used only as a
  fast, non-rank-eligible fatal-screen proxy.

## Model and mechanism

- Rabiner, L. R. (1989), *A Tutorial on Hidden Markov Models and Selected
  Applications in Speech Recognition*. The implementation uses a small
  Gaussian Markov state model and causal forward filtering.
- SMC/ICT terminology is not used as a retrospective chart label. Accumulation,
  manipulation and distribution are mapped from the 2021 fitted state
  emissions before 2022 or 2023 performance is evaluated.

No external performance claim is imported.
