# Decision boundary

This initial screen is a fatal economic test, not a ranking claim.

A path advances only when the unchanged 100ms and 300ms implementations both pass all frozen model, cost, median, concentration and drawdown gates. An advancing path must then be expanded across additional pre-2024 dates and replayed with actual Bybit funding before it can enter the cumulative strategy ranking.

A failed path is retired without adjacent changes to event thresholds, basis horizon, model family, calibration, latency, queue participation, target, stop, risk or leverage. The already decision-ready ranking reconciliation in PR #169 separately removes the forced-time-exit incumbent and promotes the no-timeout Donchian comparator provisionally.
