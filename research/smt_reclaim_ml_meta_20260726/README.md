# Explainable ML meta-label for SMT reclaim

Claim: `CLM-20260726-SMT-RECLAIM-ML-001`

## One-sentence trader explanation

After BTC displacement drives SOL or XRP beyond beta fair value and opposite flow confirms a causal MSS, the model decides whether that MSS is genuine exhaustion likely to reclaim equilibrium or only a pause before the liquidity run resumes.

## What ML is allowed to do

The model does not predict direction from arbitrary features. Direction, setup, confirmation, target, invalidation, execution latency, cost, risk and leverage are frozen before training:

1. BTC prints statistically abnormal displacement with aligned aggressive flow.
2. SOL/XRP extends farther than its prior-only beta-implied move: external-liquidity delivery and quantitative SMT divergence.
3. Residual contraction plus one completed second of opposite follower aggressor flow confirms CISD/MSS.
4. At that instant only, the model scores exhaustion versus continuation.
5. A selected setup fades toward beta-residual equilibrium. Continued displacement invalidates it.

This preserves a rule-level explanation for an SMC/ICT trader while using ML only where the discretionary question actually remains: **is the confirmed shift real?**

## Causal chronology

- Fit: six fixed 2022 Sunday partitions.
- Calibration and model/score selection: six disjoint 2022 Sunday partitions.
- Sequential development: eight fixed January–August 2023 Sunday partitions.
- Fixed post-selection evidence: the already opened September–December 2023 family dates.
- Official 2024–2026: physically prohibited.

The model and score threshold are chosen once in calibration. Development and later evidence cannot modify them.

## Minimal model set

Only two models are tested:

- sparse logistic regression as the interpretable linear control;
- shallow histogram gradient boosting for limited nonlinear interactions.

Each is evaluated at score quantiles 0.80, 0.90 and 0.95, separately for 100 ms and 300 ms execution labels. A model/quantile pair must survive both latencies. No deep network, broad architecture sweep or cosmetic feature expansion is permitted.

## Economic evaluation

Every selected event is chronologically replayed through one global SOL/XRP slot at 24 bp round-trip cost. Position size uses one-percent planned NAV risk and a 3x notional cap. The largest ten percent of positive event keys are removed before rerouting, not merely subtracted from the final ledger.

Selection is based on after-cost account growth, median trade, date breadth, concentration and winner-removal performance. Classification accuracy alone has no authority.

## Conditional authority

This study executes only when the preceding hand-specified MSS strategy records zero main survivors. If the rule strategy survives, the required next step is exact Bybit BBO/depth, funding and complete pre-2024 reconstruction; this ML study must not run.

No credentials, private endpoints, paper orders, testnet orders or live orders are used.
