# Invalidated and rejected work

`03_RESEARCH/40_INVALIDATED_AND_REJECTED`는 같은 실패를 다시 반복하지 않기 위한 지식을 보관한다.

- 입력: 누수·오류·비현실적 체결·과최적화·비용 후 음의 기대값·취약한 집중도 등으로 무효 또는 폐기된 접근
- 필수 내용: 정확한 원인, 데이터·코드·조건, 관련 result/experiment ID, 재검토 조건
- 산출물: 검색 가능한 failure knowledge
- 완료: 활성 결과·Champion에서 제외되고 후속 작업이 원인 수정 또는 다른 알파 탐색으로 이동

기록을 삭제하지 않는다. 오류 정정으로 다시 유효해지면 새로운 실험과 결과로 등록한다.
