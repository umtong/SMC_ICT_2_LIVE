# Sources and quantitative translation

The sources motivate mechanisms; neither source is evidence that crypto trading is profitable.

- **Carol L. Osler (2003), Currency Orders and Exchange Rate Dynamics** — documents clustering of stop-loss and take-profit orders and relates it to reversals at support/resistance and faster trends after those levels are crossed.
- **Carol L. Osler (2005), Stop-loss Orders and Price Cascades in Currency Markets** — provides evidence that stop-loss orders can generate rapid positive-feedback price cascades.
- **Bybit public MT4 kline archive** — official historical completed OHLCV input for the causal screen.

## SMC/ICT translation

| Trader vocabulary | Frozen observable |
|---|---|
| buy-side / sell-side liquidity | unresolved confirmed pivot cluster above / below price |
| equal highs / equal lows | multiple confirmed pivots within 0.10 ATR |
| stronger draw on liquidity | pool mass from touches, hourly participation, age and normalized local volume |
| liquidity sweep | price trades beyond the pool by 0.05 ATR |
| raid and rejection | directional close back through the consumed pool |
| accepted liquidity run | displacement close beyond the consumed pool |
| next draw | nearest unresolved pool with sufficient mass ratio and structural R multiple |

No unobservable stop order is claimed to be known. Pool mass is a transparent proxy whose economic value is tested directly.
